# T26 — Distribuição de obstáculos
Objetivo: distribuir obstáculos pelas zonas sem bloquear o caminho até as chaves, validando conectividade por BFS.
Arquivos a criar: `src/server/ObstaclePlacer.luau`.
Assinaturas: `ObstaclePlacer.posicionar(grade: MazeGrid.Grade, zonas: {Zones.Zona}, mapa: Folder): ()`; `ObstaclePlacer.caminhoValido(grade: MazeGrid.Grade, inicio: Vector2, destinos: {Vector2}): boolean`.
Critério de pronto: obstáculos surgem nas zonas e uma busca BFS confirma caminho do início a cada chave antes de aceitar cada colocação.
