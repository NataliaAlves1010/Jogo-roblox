# T26 — Distribuição de obstáculos
Objetivo: distribuir candidatos de obstáculos nas zonas; células Vector2 usam X=linha e Y=coluna, e cada chave recebe sua célula de destino.
Arquivos a criar: `src/server/ObstaclePlacer.luau`.
Assinaturas: `export type Candidato = { Celula: Vector2, Instancia: BasePart | Model }`; `posicionar(grade: MazeGrid.Grade, zonas: {Zones.Zona}, mapa: Folder, inicio: Vector2, chaves: {Vector2}, candidatos: {Candidato}): ()`.
Assinaturas: `caminhoValido(grade: MazeGrid.Grade, inicio: Vector2, destinos: {Vector2}, bloqueadas: {Vector2}?): boolean`.
Critério de pronto: cada candidato aceito é parentado à zona correta somente se BFS mantiver caminho do início a todas as chaves; candidatos que bloqueiam caminho são ignorados.
