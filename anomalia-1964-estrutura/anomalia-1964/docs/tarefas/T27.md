# T27 — Pistas
Objetivo: definir e posicionar 9 pistas coletáveis, distribuídas em 2–3 por zona.
Arquivos a criar: `src/shared/ClueData.luau`, `src/server/Clues.luau`.
Assinaturas: `export type Pista = { Id: string, Zona: Types.NomeZona, Celula: Vector2, Texto: string }`; `ClueData.obterTodas(): { ClueData.Pista }`.
Assinaturas: `Clues.inicializar(zonas: { Zones.Zona }, aoColetar: (Player, string) -> ()): ()`.
Critério de pronto: cada pista tem ID único, texto em português e posição válida; coleta validada pelo servidor aciona o callback uma única vez por jogador.
