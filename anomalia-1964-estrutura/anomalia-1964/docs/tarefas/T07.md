# T07 — Geração do labirinto
Objetivo: gerar um labirinto conectado por DFS/backtracker e adicionar ciclos extras.
Arquivos a criar: `src/server/MazeGenerator.luau`.
Dependência: T06.
Assinaturas: `MazeGenerator.gerar(linhas: number, colunas: number, seed: number): MazeGrid.Grade`.
Critério de pronto: mesmo input gera a mesma grade; todas as células são alcançáveis e há caminhos alternativos criados pelos ciclos.
