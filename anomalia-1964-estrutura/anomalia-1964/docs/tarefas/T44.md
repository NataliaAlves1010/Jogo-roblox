# T44 — Ocultação de Pistas e Ruído
Objetivo: fazer a pista desaparecer apenas para o jogador que a coletou e disparar alerta de ruído no servidor.
Arquivos: criar `src/client/CluesClient.luau`; editar `src/server/Clues.luau`, `docs/PLANO.md`.
Assinaturas: `CluesClient.inicializar(): ()`; `CluesClient.ocultarPista(pistaId: string): ()`.
Assinaturas: `Clues.notificarRuido(celula: Vector2, posicao: Vector3): ()`.
Critério de pronto: Part da pista fica invisível/sem colisão para o jogador que coletou; servidor emite ruído na célula exata da coleta.
