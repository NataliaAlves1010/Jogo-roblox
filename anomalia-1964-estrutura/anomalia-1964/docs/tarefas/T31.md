# T31 — Faxineira
Objetivo: criar a faxineira interativa nas zonas e encaminhar pedidos de conversa ao servidor.
Arquivos: criar `src/server/Janitor.luau`; editar `docs/PLANO.md`.
Assinaturas: `Janitor.inicializar(zonas: { Zones.Zona }): ()`; `Janitor.conversar(jogador: Player, faxineira: Model): boolean`.
Critério de pronto: cada interação valida personagem e distância no servidor e envia `DialogoAtualizado` com fala da zona; nenhuma fala é concedida por pedido inválido.
