# T35 — Vitória e reinício
Objetivo: mostrar a tela final com o tempo da partida e permitir reiniciar o mapa com uma nova seed.
Arquivos: criar `src/client/EndingUI.luau`; editar `src/server/Progress.luau`, `src/server/Main.server.luau`, `src/server/Inventory.luau`, `src/server/Checkpoints.luau`, `src/server/Clues.luau`, `src/server/Janitor.luau`, `src/server/HideSpots.luau`.
Arquivos: editar `src/shared/Config.luau`, `src/shared/Remotes.luau`, `src/shared/Types.luau`, `src/client/Bootstrap.client.luau`, `docs/PLANO.md`, `docs/tarefas/T35.md`.
Assinaturas: `EndingUI.exibir(tempoSegundos: number): ()`; `Progress.concluir(jogador: Player): ()`; `Progress.reiniciarMapa(jogador: Player): boolean`.
Assinaturas: `Inventory.resetarTodos(): ()`; `Checkpoints.reiniciar(zonas: { Zona }): ()`; `Clues.reiniciar(zonas: { Zona }, aoColetar: (Player, string) -> ()): ()`; `Janitor.reiniciar(zonas: { Zona }): ()`; `HideSpots.reiniciar(zonas: { Zona }): ()`.
Critério de pronto: vitória registra e exibe o tempo; reinício validado pelo servidor gera nova seed, limpa progresso e restaura mapa, checkpoint, pistas, faxineiras e esconderijos.
