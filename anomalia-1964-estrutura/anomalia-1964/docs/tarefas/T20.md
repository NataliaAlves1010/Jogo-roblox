# T20 — Interação segura
Objetivo: fornecer interações por ProximityPrompt, verificadas pelo servidor quanto à distância do jogador.
Arquivos a criar: `src/server/Interact.luau`.
Assinaturas: `Interact.criar(alvo: BasePart, texto: string, acao: (Player) -> ()): ProximityPrompt`; `Interact.distanciaValida(jogador: Player, alvo: BasePart): boolean`.
Critério de pronto: o servidor só executa a ação quando o jogador está vivo e dentro do alcance configurado no prompt.
