# T05 — Tipos e remotos
Objetivo: declarar tipos compartilhados e remotos criados e validados pelo servidor.
Arquivos a criar: `src/shared/Types.luau`, `src/shared/Remotes.luau`.
Assinaturas: `Remotes.inicializar(): Folder`; `Remotes.obter(nome: string): RemoteEvent`.
Critério de pronto: módulos iniciam com `--!strict`; servidor cria os RemoteEvents e cliente só os obtém para enviar pedidos.
