# T25 — Duto de ventilação
Objetivo: criar um atalho atravessável agachado, com movimento mais lento e inacessível ao guarda; o modelo contém BaseParts `Entrada` e `Saida`.
Arquivos: criar `src/server/Obstacles/Vent.luau`; editar `src/shared/Config.luau` para ajuste de movimento e `src/server/Guard/Vision.luau` para o guarda ignorar quem está no duto.
Assinaturas: `Vent.configurar(duto: Model): ()`; `Vent.entrar(jogador: Player, duto: Model): boolean`; `Vent.sair(jogador: Player, duto: Model): ()`.
Critério de pronto: o servidor valida entrada e saída, limita o movimento do jogador no duto e impede o guarda de segui-lo.
