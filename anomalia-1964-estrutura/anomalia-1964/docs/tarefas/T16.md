# T16 — Perseguição do guarda
Objetivo: perseguir continuamente o jogador visível e recalcular o caminho em intervalos configurados.
Arquivos a criar: `src/server/Guard/Chase.luau`.
Assinaturas: `Chase.iniciar(guarda: Model, alvo: Player): ()`; `Chase.parar(guarda: Model): ()`.
Critério de pronto: o guarda segue o alvo por caminho válido, usa velocidade configurada e para ao perder o alvo.
