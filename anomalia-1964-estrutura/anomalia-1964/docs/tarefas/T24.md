# T24 — Feixe de segurança
Objetivo: criar um feixe de luz temporizado que só permite a travessia no intervalo seguro.
Arquivos: criar `src/server/Obstacles/LightBeam.luau`; editar `src/shared/Config.luau` com tempos ativo/seguro e dimensões do feixe.
Assinaturas: `LightBeam.configurar(emissor: BasePart, destino: BasePart): ()`; `LightBeam.estaSeguro(feixe: Instance): boolean`.
Critério de pronto: o feixe alterna entre ativo e intervalo seguro usando tempos do Config, e só captura/impede travessia quando ativo.
