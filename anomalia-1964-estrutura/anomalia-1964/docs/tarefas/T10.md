# T10 — Checkpoints
Objetivo: criar um checkpoint por zona e devolver o jogador ao último checkpoint ao renascer.
Arquivos a criar: `src/server/Checkpoints.luau`.
Dependência: T09.
Assinaturas: `Checkpoints.inicializar(zonas: { Zones.Zona }): ()`; `Checkpoints.obter(jogador: Player): CFrame?`.
Critério de pronto: cada zona tem um ponto válido e o jogador reaparece no checkpoint mais recente.
