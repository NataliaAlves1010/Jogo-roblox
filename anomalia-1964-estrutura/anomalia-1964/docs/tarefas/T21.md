# T21 — Portas trancadas
Objetivo: criar portas que só abrem quando o servidor confirma que o jogador possui a chave da cor correspondente.
Arquivos a criar: `src/server/Obstacles/LockedDoor.luau`.
Assinaturas: `LockedDoor.configurar(porta: BasePart, corChave: string, validarChave: (Player, string) -> boolean): ()`; `LockedDoor.abrir(porta: BasePart): ()`.
Critério de pronto: sem a chave correta a porta permanece bloqueada; com ela, abre sem confiar em dados enviados pelo cliente.
